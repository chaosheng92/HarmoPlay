口琴谱演奏器（HarmoPlay）AI 转谱要求
================================================
【怎么用这份文档】
把本文件**全文复制**给任意大模型，再附上你的音频 / MIDI / 五线谱 / 简谱图片，说：
"按这份要求帮我转谱"。拿到 JSON 后先用本软件的「导入曲谱文件…」或
`口琴谱演奏器.exe --validate 曲名.json` 校验，再导入。

【一、必须交付的内容】
1. 一个 UTF-8 编码的「曲名.json」，可直接导入本软件，字段**只有**这五个，名称与大小写必须一致：
   {
     "Name": "曲名",
     "Score": "1 1 5 5 | 6 6 5:2 |\n4 4 3 3 | 2 2 1:2 |",
     "Bpm": 120,
     "Meter": "4/4",
     "Enabled": true
   }
   · Name：字符串，写清曲名；有移调、节选、改编请在名称里标出（如「暂定速度」「片段」）。
   · Score：只放音符、休止、空格、换行、小节线；不得放歌词、调号、速度文字、任何注释。
   · Bpm：20~400 的整数；图片看不出速度时用合理暂定值，并在说明里写明"暂定"。
   · Meter：如 "4/4" "3/4" "6/8"。
   · Enabled：布尔值 true（不能是字符串 "true"）。
2. 一个「曲名-说明.txt」：来源、选取的声部、原调号与换算过程、拍号、BPM（是否暂定）、
   音域（最低/最高音名与 MIDI）、反复如何展开、装饰音如何处理、以及所有不确定之处。
3. 如需要，再给「曲名-纯简谱.txt」，内容必须与 JSON 的 Score **逐字符一致**。
4. 如果平台不能发文件，就直接输出完整 JSON 原文，让用户自己另存为 UTF-8 的 .json。

【二、Score 语法（严格，违反即无法导入）】
每个音符的格式：[可选的 # 或 b][数字 1~7][可选的英文单引号 ' 或英文逗号 ,][可选的 :十进制拍数]
· 正则：^([#b]?)([0-7])([',]?)(?::([0-9]+(?:\.[0-9]+)?))?$
· 休止符：0 或 0:拍数。音符之间用空格或换行分隔。| 是小节线，只供阅读，不计时。
· 只允许 ASCII 半角字符：# b , ' : . 数字 空格 换行 竖线。
· 禁止：
  ① 连写数字（1234）；② 数字 8、do/re/mi、C4 之类音名（本软件不用 8）；
  ③ 中文逗号、弯引号、♯、♭、真实的上下加圆点；④ 1-、下划线、延音弧、连音弧、反复记号、D.C./D.S.、歌词；
  ⑤ 分数时值（1:1/2 要写成 1:0.5）；⑥ 带修饰的休止（#0、0'、0,）；⑦ 和弦、力度、踏板、滑音、音色等指令。
· 单个音或休止的时值必须在 0.03125 ~ 64 拍之间，且是有限十进制数。

【三、音高（固定音高记法，中音 1 = C4 = MIDI 60）】
数字**不随源谱调号改变**，永远是固定音高：
  1=C4  2=D4  3=E4  4=F4  5=G4  6=A4  7=B4
  1,=C3 2,=D3 … 7,=B3        （逗号 = 低八度）
  1'=C5 2'=D5 … 7'=B5        （单引号 = 高八度）
  黑键优先用 # 表示：#1=C#4、#2=D#4、#4=F#4、#5=G#4、#6=A#4；
  等音写法（b2、b3…）也能解析，但整首请统一，且能简化的就简化（如 b4→3、#3→4）。
· **可演奏音域 C3 ~ C6（MIDI 48 ~ 84）**。低于 C3、高于 C6 的一律不许输出：
  最低写 `1,`（C3），最高写 `#7'`（C6，本软件会自动用「逗号键 + 右键」演奏）。
  禁止 `1''`、`1,,`、`C#6` 这类无法表达的写法。
· 若原曲超出音域：**列出具体位置、源音名与 MIDI，并给出整体移调方案，等用户同意后再改**，
  不要静默换八度、换邻近音或删音。

【四、调号与首调简谱的换算】
源谱若是 1=C 且音区一致，数字可以直接用；若是 1=D、1=E、1=bE 等首调唱名，
必须先算实际音高再编码成上面 1=C 的固定写法（否则整首音高全错）：
  自然音级相对主音的半音数：1=0，2=2，3=4，4=5，5=7，6=9，7=11
  源音 MIDI = 源谱主音 MIDI + 音级半音 + 源音升降值 + 音区偏移（下方一点 −12，上方一点 +12）
  示例：源谱 1=E（未加点的 1 视为 E4）时，源 1 2 3 4 5 6 7 → 软件写法 3 #4 #5 6 7 #1' #2'

【五、节奏换算（一拍恒为四分音符）】
  全音符=4拍  二分=2拍  四分=1拍  八分=0.5拍  十六分=0.25拍  三十二分=0.125拍
  附点四分=1.5拍  附点八分=0.75拍      秒数 = 拍数 × 60 ÷ BPM
· 三连音示例（三音合计一拍）：1:0.333333 2:0.333333 3:0.333334
· 六连音等必须用十进制近似，并调整最后一个音使整组时值**精确等于**原总拍数，不能让误差累积。
· 拍号只作标记，软件不会自动补拍：4/4 每小节 4 拍、3/4 每小节 3 拍、6/8 每小节 3 拍（四分音符拍）。
  弱起小节可以不足拍，结尾通常与弱起互补——必须在说明里指出。
· 源速度标「附点四分音符=60」的 6/8 曲，本软件 BPM 应填 90（因为以四分音符为一拍）。
· 一首 JSON 只能有一个 BPM：曲中变速要么拆成多个 JSON，要么统一折算（说明里必须列出折算的小节）。

【六、延音、连奏、装饰音、反复、声部】
· 同音延音线要合并成一个长音（两个连起来的一拍 1 → `1:2`，不能写 `1 1`）；跨小节同理，小节线可省。
· 不同音高之间的连奏弧**不要**合并，仍逐音输出。
· 倚音、波音等装饰音无法原样表达：给它分配明确时值（常用 0.125 拍），并从相邻主音扣掉相同时值，
  保证小节总拍数不变，并在说明里写明处理方式。
· Score 不支持反复记号：普通反复、一二房、D.C.、D.S.、Segno、Coda、A/B/C 段都要**展开**成实际演奏顺序，
  展开后重新核对小节数与总拍数。
· 只支持单声部：钢琴谱/合奏谱/多声部 MIDI 默认提取主旋律，**不得**把和弦音一个接一个塞进 Score 冒充同时发声；
  主旋律不明确时要说明你选了哪个声部。改成琶音属于改编，必须先经用户同意。

【七、演奏可行性：口琴 8 键 + 鼠标变调（务必遵守）】
游戏里是 8 个键 + 鼠标变调，程序会按目标音高自动选指法：
  键：z=1  x=2  c=3  v=4  b=5  n=6  m=7  ,=1'（高音 1）
  鼠标：左键=降一个八度、中键=升一个半音、右键=升一个八度
· 中键 + 左键 / 右键的**组合按法技术上可行，但人手很难同时按出**，不推荐。
· 因此请**尽量让旋律待在 C4 ~ B4（中音区）**：这一段黑键只需按住中键，不需要任何组合。
· 只有下面 9 个音不得不用组合键，**能避开就避开**（移调或改成相邻自然音，改不动要在说明里讲）：
  C#3 D#3 F#3 G#3 A#3（写法 #1, #2, #4, #5, #6,）
  D#5 F#5 G#5 A#5（写法 #2' #4' #5' #6'）
· 否则不要写需要「同时按两个鼠标键」的其它情况。

【八、交付前逐项自检（请把结果报出来）】
  1. JSON 能被标准解析器读出；2. 只有 Name/Score/Bpm/Meter/Enabled 五个字段且类型正确；
  3. Score 每个词元都符合第二节的正则；4. 每个时值在 0.03125~64 之间；
  5. 每个音都在 C3~C6（MIDI 48~84）内；6. 每个完整小节拍数符合 Meter（弱起/尾小节/折算需说明）；
  7. 三连音、六连音每组的时值之和正确；8. 同音延音已合并、不同音连奏没有误合并；
  9. 反复与房子已按正确顺序展开；10. 总拍数、BPM、预计秒数互相一致；
  11. Score 里没有歌词、调号、速度文字、力度、踏板、排版符号；
  12. 纯简谱 TXT 与 JSON 的 Score 逐字符一致。
  用户拿到文件后还可以用软件自检：`口琴谱演奏器.exe --validate 曲名.json`
  （会检查语法、时值、音域、小节拍数，并标出需要鼠标组合键的音）。请提醒用户做这一步。

【九、不确定的信息不要猜】
图片模糊、临时升降号不清、上下加点无法确认、拍数矛盾、声部不明、反复路线有歧义时，
**列出具体小节与音符请用户补充**；只缺 BPM 时可先用暂定值，但必须标注"暂定"。
禁止静默做出会改变旋律的决定。

【十、最终任务指令（可直接照做）】
请按以上全部要求，把我提供的材料转成「口琴谱演奏器 HarmoPlay」可直接导入的单声部 JSON 曲谱：
先说明曲名、主旋律声部、调性、拍号、BPM、反复结构与音域；
再完成固定音高换算、节奏换算、反复展开、同音延音合并、音域与"是否需要鼠标组合键"的检查；
遇到超出 C3~C6、模糊音符或会改变旋律的歧义时，列出准确位置向我确认，不要自行替换；
最后给出「曲名.json」「曲名-说明.txt」（需要时再给「曲名-纯简谱.txt」），
并逐项报告第八节的自检结果（源小节数、展开后小节数、总拍数、预计时长、最低/最高音与 MIDI、
哪些音需要鼠标组合键、语法错误数）。

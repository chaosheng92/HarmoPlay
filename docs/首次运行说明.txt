口琴谱演奏器 —— 首次运行说明
================================================

1) Windows 弹出蓝色窗口「Windows 已保护你的电脑 / 发布者未知」
   这是微软 SmartScreen 对「未签名的、下载量还不大的程序」的通用提示，
   不是杀毒软件报毒，也不是程序里有什么东西。
   处理办法（任选其一）：
     · 点左边「更多信息」→ 右下角「仍要运行」；
     · 或右键 exe →「属性」→「常规」页底部勾选「解除锁定(Unblock)」→ 确定，再双击。
   如果企业策略完全禁止未签名程序，请让管理员放行，或自行编译（源码在仓库里）。

1.5) 另一个弹窗：「Windows 安全中心 → 打开这些文件可能会对你的计算机有害
      —— 你的 Internet 安全设置阻止打开一个或多个文件」
   这是 Windows 给"从网上下载的压缩包"打的**下载标记（Mark of the Web）**造成的，
   和上面那个 SmartScreen 提示不是一回事。处理办法（任选其一）：
     · 最简单：右键压缩包 →「属性」→ 常规页底部勾选「解除锁定(Unblock)」→ 确定，再解压；
     · 或先解压，再把整个文件夹解锁——本包内附「解除下载锁定.cmd」，放到该文件夹双击即可；
     · 或命令行（PowerShell）：
         Unblock-File .\HarmoPlay-1.0.0-win-x64.zip
         Get-ChildItem .\HarmoPlay-1.0.0-win-x64 -Recurse | Unblock-File
     · 或把压缩包先复制到本地磁盘（如 D:\、F:\）再解压，有些环境下复制即清除标记。
   根本解决办法同样是代码签名（见 docs/代码签名.md）。

2) 想彻底消除这个提示：需要给 exe 做代码签名
   · EV 代码签名证书：签名后很快就有信誉，几乎不再提示（较贵，需要企业资质）；
   · OV 代码签名证书：签名后仍需一段下载量来积累信誉（便宜些）；
   · 本项目已经在打包脚本与 GitHub Actions 里预留了签名步骤，
     配置证书后推一个 v* 标签就会自动签名并发布，见 docs/代码签名.md。

3) 在游戏里使用（重要）
   · 游戏以管理员身份运行时，本程序也必须右键 →「以管理员身份运行」，否则游戏收不到模拟按键；
   · 游戏请用「无边框窗口 / 窗口化」显示，独占全屏会盖住悬浮窗；
   · Win11：设置 → 系统 → 屏幕 → 显示卡 → 关掉「窗口化游戏优化」和「自动 HDR」；
     游戏 exe → 属性 → 兼容性 → 勾「禁用全屏优化」；
   · 还是没反应？点「键位与设置 → 输入安全 → 输入自检」，它会直接告诉你原因。

4) 悬浮窗怎么摆位置（两种方式）
   · 快捷：按 Alt+L 解锁 → 悬浮窗出现橙色边框和「≡ 按住这里拖动我」，
     按住窗口任意位置拖动即可；Ctrl+滚轮缩放；调好后按 Alt+L 锁定（点击穿透，不挡游戏）；
     解锁状态下右键还有菜单（切换模式 / 复位 / 隐藏）。
   · 精确：「键位与设置 → 悬浮窗」里有 X / Y 输入框与 ←↑↓→ 微调按钮，还有「居中」。

5) 悬浮窗两种模式（Alt+M 切换，或右键菜单 / 设置里选）
   · 音游下落（默认）：音符按节奏从上往下落，落到最下面的判定线时按键，像音游；
     顶部会显示连击数，落点有命中闪光。下落速度与提前量在设置里调。
   · 经典堆叠：音符块从下往上堆在 8 条通道里，最下面一块就是当前该弹的音。

6) 演奏方式（用户自选，Alt+T 切换）
   · 自动弹奏：程序模拟键盘/鼠标按键（有被判定违规的风险，首次开启会弹风险提示，
     点「不同意」就不会开启）；
   · 跟谱弹奏：程序不发任何按键，只把悬浮窗/主界面当谱面，等你按对当前的音再走下一个。

7) 免责声明
   见软件顶部常驻横幅；点「完整声明」可看全文，也可随时收起。

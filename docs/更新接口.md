# 更新接口说明

软件启动后可以从仓库里的一个 JSON 文件读取最新版本信息，提示用户升级。**不需要服务器**，直接放在 GitHub 仓库里即可。

## 1. 清单文件 `update.json`

放在仓库根目录（默认分支），格式：

```json
{
  "version": "1.0.1",
  "published": "2026-10-02",
  "notes": "新增：音游下落模式；修复：b7 高音指法",
  "download": "https://github.com/chaosheng92/HarmoPlay/releases/latest",
  "mandatory": false,
  "sha256": "可选，发布包校验值"
}
```

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `version` | ✅ | 最新版本号，和 `HarmoPlay.csproj` 的 `<Version>` 对应；比较采用语义化版本，`v1.0.1` 和 `1.0.1` 都认 |
| `notes` | | 更新说明，会显示在弹窗里 |
| `download` | | 下载页/直链，点「打开下载页」时打开它 |
| `published` | | 发布日期，纯展示 |
| `mandatory` | | `true` 时提示语气更强（不会强制拦截） |
| `sha256` | | 发布包的 SHA256，便于手动校验 |

## 2. 客户端怎么用

- 图形界面：「设置 → 更新与反馈」→ 填/确认**更新地址** → 点「检查更新」。
- 命令行：`HarmoPlay.exe --checkupdate`（结果写到 `update-check.log`，便于脚本/CI 验证）。
- 更新地址支持 `https://`、`http://` 与本地 `file://`（方便自己测清单格式）。
- **只检查、不自动安装**：发现新版本后弹窗询问，确认就打开下载页。这样最安全，也不会因为自动替换 exe 被杀软拦。

默认地址写在 `src/Models/Song.cs` 的 `AppSettings`（`UpdateUrl` / `DownloadUrl` / `DouyinUrl` / `QqGroup`），
上传到自己仓库后，把里面的 `chaosheng92/HarmoPlay` 改成实际地址即可；也可以直接在软件界面里改（会存进 `data/settings.json`）。

## 3. 发版流程（已内置 GitHub Actions）

仓库里带了一个工作流 `.github/workflows/release.yml`：**推一个 `v*` 标签就自动发版**。

```bash
git tag v1.0.1
git push origin v1.0.1
```

工作流会：

1. 在 windows-latest 上装 .NET 8 SDK；
2. `dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true`；
3. 把 exe、5 个原生 DLL、`Assets/Seed`、`使用说明.txt` 打成一个 zip；
4. 计算 SHA256，创建 GitHub Release 并上传 zip；
5. 用新版本号、说明、下载地址更新仓库里的 `update.json` 并提交回默认分支。

这样老用户下次点「检查更新」就能看到新版本。

## 4. 本地打包（不想用 CI 时）

```powershell
pwsh -File tools/make-release.ps1 -Version 1.0.1 -Notes "修复 xxx"
```

脚本会产出：

- `dist/HarmoPlay-1.0.1-win-x64.zip`（发布包）
- 更新后的 `update.json`（含版本号、说明、下载地址、SHA256）

把它连同 zip 一起上传到 Release，并把 `update.json` 提交到仓库即可。

## 5. 注意事项

- 不要用 `-p:IncludeNativeLibrariesForSelfExtract=true`：那会让程序把原生库解压到 `%TEMP%\.net`，
  在某些被 ACL 限制的用户目录下会直接启动失败。当前发布方式是「托管程序集内嵌进单文件 exe + 5 个 WPF 原生 DLL 放同目录」。
- 更新地址若填 `raw.githubusercontent.com`，国内网络可能需要代理；也可以用 jsDelivr 之类的 CDN 地址。
- 清单必须是**纯 JSON**（不能有注释），版本号不要带 `v` 前缀以外的多余字符。

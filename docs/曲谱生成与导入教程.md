# 曲谱生成与导入教程（AI 转谱 → 校验 → 导入）

HarmoPlay 支持三种曲谱记法，其中**固定音高记谱**是「AI 转谱」的正规路线：
拿音频 / MIDI / 五线谱 / 简谱图片，让 AI 按规范输出一个 `曲名.json`，校验通过后直接导入。

> 规范原文见 [docs/AI转谱要求-原文.txt](AI转谱要求-原文.txt)，**原样复制粘贴给 AI 即可**。
> 本教程是它的操作版：怎么问、怎么验、怎么导、常见坑在哪。

---

## 0. 总览：三步走

| 步骤 | 做什么 | 用什么 |
| --- | --- | --- |
| 1 | 准备源材料（音频 / MIDI / 谱面图片） | 你自己的文件 |
| 2 | 把规范原文 + 源材料丢给 AI，拿回 `曲名.json` + `曲名-说明.txt` | 任意支持附件的大模型 |
| 3 | 本地校验 → 导入 → 试听 → 实播 | `HarmoPlay.exe --validate` + 软件界面 |

---

## 1. 源材料怎么准备

- **音频**：整首歌即可；人声歌建议先说明"要主旋律、不要伴奏"。
- **MIDI**：最好给单声部主旋律；多声部要让 AI 明确说明取的是哪一轨。
- **五线谱 / 简谱图片**：清晰、能看清调号与上下加点；模糊图必须让 AI 停下来问你，不要让它猜。
- **调号**：源谱如果是 `1=D`、`1=bE` 这类首调简谱，**AI 必须换算**成软件的固定 `1=C` 写法，直接把数字抄过来会整体移调。

## 2. 怎么问 AI（可直接复制的模板）

```
你是口琴谱转谱助手。请严格按下面这份规范，把我提供的源材料转成 JSON 曲谱。

【规范原文】
<<< 把 docs/AI转谱要求-原文.txt 的全文粘贴到这里 >>>

【我的源材料】
<<< 上传音频 / MIDI / 谱面图片 >>>

要求：
1) 先报告：曲名、主旋律声部、调性、拍号、BPM、反复结构、音域（最低/最高 MIDI）。
2) 再输出：曲名.json（UTF-8，字段只允许 Name/Score/Bpm/Meter/Enabled）
   和 曲名-说明.txt（来源、声部、调号换算、时值折算、装饰音处理、不确定处）。
3) 遇到超出 C3~C6、模糊音符、拍数矛盾，必须列出具体小节并问我，不许自行替换或删音。
4) 交付前逐项执行规范第十一节的校验，并报告校验结果。
```

拿到文件后建议看一眼说明文件里的"暂定 BPM""移调"这些字眼——它们代表你不该无条件相信这份谱。

## 3. 本地校验（关键一步）

图形界面导入时会自动提示校验结果；**命令行可以批量校验**：

```bat
HarmoPlay.exe --validate "D:\曲谱\晴天.json"
HarmoPlay.exe --validate "D:\曲谱\晴天.json" "D:\曲谱\小星星.json"
```

报告会写进同目录的 `validate.log`，内容包括：

- JSON 字段与类型（缺字段、`Enabled` 写成字符串都会报错）
- 每个记号是否符合 `^([#b]?)([0-7])([',]?)(?::拍数)?$`
- 时值是否在 `0.03125 ~ 64` 拍
- 音高是否在 C3~C6（MIDI 48~84），越界会明确指出是哪个记号
- 每小节拍数是否符合拍号（弱起 / 结尾小节会作为警告列出）
- 总拍数、BPM、预计时长、是否需要中键 / 八度键

**判定标准：错误（✖）必须为 0 才导入；警告（⚠）逐条人工确认。**

## 4. 导入

| 方式 | 操作 |
| --- | --- |
| 图形界面（推荐） | 工具栏「导入曲谱文件…」→ 选中 `曲名.json`（可多选）→ 自动落到「导入曲谱」分类，记谱法自动设为固定音高 |
| 拖进目录后批量导入 | `HarmoPlay.exe --import "D:\曲谱文件夹"`（txt 与 json 都吃） |
| 手工粘贴 | 「编辑曲谱」页把 `Score` 字段内容粘进去，记谱法下拉选「固定音高」 |
| 外部曲库（library.json） | 工具栏「导入外部曲库」→ 选 `%LOCALAPPDATA%\HarmonicaMacro\Data\library.json` |

导入后先看「曲谱库」页右侧的**键位映射表**和预览里的 `键位 Z(C4)` 标注，确认音高对得上再实播。

## 5. 试听与实播

- `Alt+1` 播放/暂停，`Alt+2` 停止；先在桌面空窗口试一遍，确认节奏与按键。
- 悬浮窗两种模式：「经典堆叠」（看最下面一块）和「音游下落」（音符落到判定线时按键）。
- 想自己练：勾「跟练模式」（`Alt+T`），软件不发按键，等你按对才走下一个音。
- 实播后如果游戏没反应：以管理员身份运行、游戏改无边框窗口、关掉 Win11「窗口化游戏优化」。

## 6. 固定音高对照表（C3~C6，MIDI 48~84）

写谱时**只写目标音高**，指法由程序自动选择。

### ⚠ 关于「中键 + 左/右键」组合：能用，但不推荐

三角洲行动里**可以**同时按住中键和左键（或右键），但**人手很难做到**。因此：

- 程序默认开启「**优先选择不需要组合的指法**」，例如最高音 C6 会自动改成
  「**逗号键 + 右键**」而不是「M + 右键 + 中键」；
- 只有实在没有更简单指法时才会用组合——也就是下面这 9 个音：

| 只能用组合键的音 | 简谱写法 | 需要的组合 |
| --- | --- | --- |
| C#3 D#3 F#3 G#3 A#3 | `#1,` `#2,` `#4,` `#5,` `#6,` | 左键 + 中键 |
| D#5 F#5 G#5 A#5 | `#2'` `#4'` `#5'` `#6'` | 右键 + 中键 |

- **自动弹奏**没问题（程序按得出来）；但你自己**跟谱弹奏**时基本按不了这几个音；
- 所以转谱时建议：**让旋律尽量待在 C4~B4（中音区）**——这一段的黑键只要按住中键，不需要组合键；
- 程序会在预览里给这些音标注，`--validate` 也会警告并列出具体位置（不阻止导入，只提醒你）。

> 如果将来遇到**真的按不出组合键**的游戏：在「键位映射…」里取消勾选「允许中键+左键/右键」，
> 这 9 个音就会被标记为 **✗ 无法演奏**并在演奏时跳过。

### 完整对照表（含实际按键）

| 简谱写法 | 音名 | MIDI | 程序实际按键 | 备注 |
| --- | --- | --- | --- | --- |
| `1,` | C3 | 48 | Z + 左键 | |
| `#1,` | C#3 | 49 | Z + 左键 + 中键 | 需要组合，人手难按 |
| `2,` … `7,` | D3 … B3 | 50~59 | X…M + 左键 | 黑键需要组合 |
| `1` … `7` | C4 … B4 | 60~71 | Z…M（黑键按住中键） | ✅ 推荐音区 |
| `1'` | C5 | 72 | 逗号键 `,` | |
| `#1'` | C#5 | 73 | 逗号键 + 中键 | |
| `2'` … `7'` | D5 … B5 | 74~83 | X…M + 右键 | 黑键需要组合 |
| `#7'` | C6 | 84 | 逗号键 + 右键（自动避开组合） | 也可以写成 M+右键+中键 |

- 中键 = **升**半音；左键 = 降八度；右键 = 升八度；左键与右键不能同时按。
- 音域上限 C6 只能写成 `#7'`；`1''`、`1,,`、`C#6` 这类写法规范里禁止输出。

## 7. 常见错误清单（AI 最常犯）

1. 把 `b2`（= C#4）写成 `2,`（= D3）——**降号是半音，不是低八度**。
2. 出现数字 `8`、`do/re/mi`、`C4` 之类音名（规范只允许 1~7）。
3. 用中文逗号、`♯`/`♭`、上下圆点（必须 ASCII 半角）。
4. 写分数时值 `1:1/2`（必须小数）、写 `1-` 延音、写连音弧。
5. 同音延音没合并（该写 `1:2` 却写 `1 1`）。
6. 反复记号（D.C./D.S./房子）没展开成实际演奏顺序。
7. 多声部把和弦音一个接一个塞进单声部。
8. 超出 C3~C6 不报告、自行移调或删音。
9. `Meter` 与实际小节拍数不一致（弱起小节没在说明里标注）。
10. `Enabled` 写成字符串 `"true"`，或 JSON 里混入注释。
11. **写了需要「中键+左/右键」组合的音**（低/高八度黑键，如 `#1,` `#2'`）——技术上能弹，
    但人手很难同时按出，自己跟谱弹奏基本按不了；建议把旋律移调到中音区 C4~B4
    （这一段黑键只需按住中键）。`--validate` 会专门警告并列出具体位置。

## 8. 两种记谱法的区别（Import 之后可切换）

| | 固定音高（转谱规范） | 直接按键（可视化谱 / D-hydra) |
| --- | --- | --- |
| 谁决定指法 | 程序按音高自动选 | 曲谱直接写明鼠标键 |
| `b` 的含义 | 降半音 | 降八度（左键） |
| `^` 的含义 | 升八度（`'` 的等价写法） | 升八度（右键） |
| `,` / `'` | 低 / 高八度 | 低 / 高八度 |
| 典型来源 | AI 转谱 JSON、外部曲库 | 三角洲可视化谱、D-hydra 键位谱 |

导入时程序会自动判断（有显式时值 `1:0.5` → 固定音高；`TITLE=` / 键位列 → 直接按键），
判断不对时在「编辑曲谱」页的**记谱法**下拉里手动切换即可，预览会立刻重算。

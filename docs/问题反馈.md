# 问题反馈通道

反馈入口：**GitHub Issues** —— 软件里「键位与设置 → 更新与问题反馈 → 反馈问题（GitHub Issues）」一键打开。

## 1. 反馈前先拿好诊断包

点软件里的「**导出诊断包**」（或命令行 `HarmoPlay.exe --feedback`），会在 `data/feedback/` 下生成
`HarmoPlay-诊断-<时间>.txt`，里面包含：

- 程序版本、运行目录、数据目录、是否管理员运行
- Windows 版本、.NET 版本、CPU 核数、屏幕分辨率
- 当前键位映射、演奏参数、悬浮窗与下落模式设置
- 全局热键列表
- `startup.log` / `error.log` 的最近若干行

**诊断包不包含你的曲谱内容**，可以放心上传。

## 2. 提 Issue 时请写清

1. 复现步骤（点了什么、按了什么热键）
2. 期望结果 vs 实际结果
3. 游戏名与显示模式（窗口化 / 无边框 / 独占全屏）
4. 是否以管理员身份运行
5. 是否开了跟练模式、悬浮窗是哪种模式
6. 附上诊断包；界面问题再附一张悬浮窗截图

仓库里有 Issue 模板（`.github/ISSUE_TEMPLATE/bug_report.yml`），按模板填不容易漏信息。

## 3. 常见问题（先自查，可能省一次往返）

| 现象 | 排查 |
| --- | --- |
| 游戏里没反应 | **先点「键位与设置 → 输入安全 → 输入自检」**（或双击包里的 `输入自检.cmd`）：报告会直接告诉你模拟输入是否被系统接受、原因是什么。若正常，再检查：管理员身份运行 / 游戏改无边框窗口 / 关「窗口化游戏优化」+「自动 HDR」/ 勾「禁用全屏优化」 |
| 悬浮窗看不见 | 独占全屏会盖住它；`Alt+H` 切换显隐；`Alt+L` 解锁后确认没被拖到屏幕外 |
| 音符按得对但游戏判定错 | 检查记谱法是否选对（固定音高 / 直接按键）；看预览里的 `键位 X(C4)` 是否与预期音高一致 |
| 某些音被跳过 | 该音超出 C3~C6，状态栏会提示；用 `--validate` 看具体是哪个记号 |
| 按键粘住不松 | 按 `Alt+2` 停止会释放所有键；若游戏内仍异常，切换一次窗口焦点 |
| 热键没反应 | 提示「已被其它程序占用」就换一个组合（如 Ctrl+Alt+1） |
| 导入的谱子节奏不对 | 确认 `BPM` 与拍号；弱起小节属正常，看 `--validate` 的警告 |
